# 项目设计与验证概览

Cardinal Agent 是可嵌入的 Python Agent Harness，以员工个人助手作为参考应用。核心价值是统一工具执行与审批、上下文与记忆管理，以及可核对的故障恢复；文档/邮件检索用于验证业务流程。

完整阅读路径见 [文档导航](README.md)，模块职责见 [架构说明](architecture.md)，数据集与测试结果见 [评测记录](evaluations/README.md)。

## 核心能力

1. 通用 create_session 接口与文本/原生工具协议统一的校验、审批和执行路径。
2. 原子 checkpoint、操作 ID、结果核对回调与 SQLite 事务示例。
3. 真实子进程 SIGKILL 后的新进程恢复，以及运行状态 CLI。
4. 带来源的检索、结构化上下文和范围化记忆，最后展示完整评测证据。

当前功能提交 a5380d2 的离线回归为 **424 passed，13 live deselected**，包含 6 个进程故障场景及 24 个原生适配器测试。历史综合真实模型评估为 **18/20**；两个指标来自不同阶段、不同验证方式，不能合并成当前模型成功率。

先展示 `cardinal init --demo` 和离线检索，再展示故障测试、状态与原始记录。新 Harness 功能尚未包含在已发布的 v0.1.1 附件中，演示时使用当前源码。

当前适合单用户本地试用与工程验证，尚无企业生产部署或人工节时对照。功能边界和后续路线见 [成熟度说明](product-readiness.md)。
